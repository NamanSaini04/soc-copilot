# Security policy

This repository is a defensive portfolio demonstration. Do not connect it to production telemetry or expose its demo services to the internet.

## Reporting a vulnerability

Open a private security advisory in the future GitHub repository. Do not include real credentials, personal data, production logs, or live malicious indicators in a public issue.

## Deployment requirements

Before deployment, add authenticated identity, role-based authorization, tenant and incident scopes, secrets management, immutable audit logging, rate limits, TLS, dependency and container scanning, data retention controls, backups, and explicit approval enforcement at the execution layer.
